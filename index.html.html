1. Apa itu Ukuran Pemusatan Data?

Ukuran pemusatan data adalah nilai yang mewakili sekumpulan data. Ada tiga ukuran utama:

  • Mean (rata-rata): jumlah semua data dibagi banyak data.
  • Median: nilai tengah setelah data diurutkan dari terkecil ke terbesar.
  • Modus: nilai yang paling sering muncul.
Mean = (x₁ + x₂ + … + xₙ) ÷ n

2. Cara Menentukan Median

Langkah: (1) urutkan data, (2) tentukan banyak data (n), (3) cari nilai tengahnya.

n ganjil: Median = data ke-(n+1)/2
n genap: Median = (data ke-n/2 + data ke-(n/2 + 1)) ÷ 2

Contoh

Data: 7, 3, 9, 5, 8 → urut: 3, 5, 7, 8, 9 → n = 5 (ganjil) → median = data ke-3 = 7.

Data: 4, 6, 8, 10 → n = 4 (genap) → median = (6 + 8) ÷ 2 = 7.

3. 🧪 Coba Sendiri: Kalkulator Interaktif

Masukkan data (pisahkan dengan koma), lalu lihat langkah-langkahnya.

4. Rangkuman

  • Selalu urutkan data dulu sebelum mencari median.
  • Banyak data ganjil → median adalah satu nilai di tengah.
  • Banyak data genap → median adalah rata-rata dua nilai di tengah.
  • Modus bisa lebih dari satu, atau tidak ada jika semua data muncul sama banyak.
